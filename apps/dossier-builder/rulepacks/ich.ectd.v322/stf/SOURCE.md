# ICH Study Tagging File DTD

`ich-stf-v2-2.dtd` — the ICH eCTD Study Tagging File DTD, version 2.2, as ICH publishes it
(`admin.ich.org/sites/default/files/inline-files/ich-stf-v2-2_dtd_0.zip`, taken 13/11/2026,
SHA-256 `e6d47695501e263534a89a2b7bf7018c92e12a11c3dd82fc1d0c462bfa52c81f`).

The rules for its use are in the ICH eCTD STF Specification v2.6.1 (3 June 2008), kept in
`docs/ctd/sources/ectd/ICH_eCTD_STF_Specification_v2.6.1_2008.pdf` (from the FDA, `fda.gov/media/159383/download`).

Who takes a study tagging file (the specification, p. 3): the United States requires one for the studies of
Modules 4 and 5; Europe does not require it (the EU harmonised technical guidance v6.0.1 §3.6.2 asks that it be
removed when a US dossier is reused, and a node-extension per study used instead); Japan does not allow it.
EDA's drafts do not mention it and ask for a node-extension per study (EG Module 1 eCTD specification draft v1.0, p. 9).
