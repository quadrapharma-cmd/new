# Bilingual Deliverable Templates

Four forms cover almost every regulatory output. Adapt structure to the case — these are scaffolds, not forms to fill mechanically.

Rules applying to all four:

- English first, Arabic second, each version complete on its own.
- Keep INNs, product names, registration numbers, decree numbers, and tracking IDs in original form in both versions.
- Dates as DD/MM/YYYY.
- Every requirement carries its source authority and citation.

## Contents

1. Regulatory position memo
2. Submission / reply letter to an authority
3. Requirements checklist
4. Comparative table

---

## 1. Regulatory position memo

For decisions: does this need a study, which pathway applies, can we classify it this way.

```
REGULATORY POSITION — [Subject]
Product: [name, dosage form, strength] | Reg. No.: [if any]
Prepared: DD/MM/YYYY | Authority: [EDA / NFSA / other]

1. QUESTION
   One sentence. What is actually being decided.

2. POSITION
   The answer, up front. Two or three sentences.

3. BASIS
   - [Requirement] — [Guideline, edition, section] / [Decree No./Year, Article]
   - [Requirement] — [source]
   Each bullet traceable. Mark anything inferred as inferred.

4. ANALYSIS
   How the rule applies to these facts. Exemptions relied on. Where
   the guidance is silent, and what fills the gap.

5. COMPARATOR VIEW (where relevant)
   EMA / WHO / ICH position and whether EDA has aligned to it.

6. OPTIONS
   Option A — [action]: timeline, cost, risk
   Option B — [action]: timeline, cost, risk

7. RECOMMENDATION
   One option, with the reason and the next concrete step.

8. OPEN POINTS
   What could not be verified and who should be asked.
```

Arabic mirror: `الموقف التنظيمي` / `السؤال` / `الموقف` / `الأساس النظامي` / `التحليل` / `الخيارات` / `التوصية` / `نقاط معلقة`

## 2. Submission / reply letter to an authority

For replies to comments, waiver requests, clarifications, notifications. Formal register in Arabic.

```
[Company letterhead]
Ref: [internal ref] | Date: DD/MM/YYYY
To: [Name and title], [General Administration], [Central Administration]
    Egyptian Drug Authority
Subject: [precise subject — include product, Reg. No., Tracking ID]
Reference: [EDA letter no. and date / Tracking ID / prior submission]

Opening — one sentence stating the purpose.

Body:
  - Each EDA comment restated, then answered directly beneath it.
  - Requests supported by citation to EDA's own guideline first.
  - Attachments referenced by name and number.

Closing — what is requested of the authority, specifically.

Attachments:
  1. [name]
  2. [name]

[Name], [Title]
[Company]
```

Arabic version:

```
السيد الأستاذ الدكتور / [الاسم]     [المنصب]
الإدارة المركزية لـ[...] — هيئة الدواء المصرية

تحية طيبة وبعد،،،

الموضوع: [الموضوع — المستحضر، رقم التسجيل، رقم التتبع]
الإشارة: [خطاب سيادتكم رقم [...] بتاريخ [...]]

[المتن — كل ملاحظة يتبعها الرد مباشرة، مع الاستناد إلى
الدليل الإرشادي / القرار الوزاري بالرقم والمادة]

وتفضلوا بقبول فائق الاحترام والتقدير،،،

المرفقات:
١- [...]
٢- [...]

[الاسم] — [الصفة]
[الشركة]
```

Answer each comment separately and visibly. A merged narrative reply invites a second round of comments because the reviewer cannot tick items off.

## 3. Requirements checklist

For assembling a file.

| # | Requirement | Source (guideline/decree + section) | Authority | Status | Owner | Notes |
|---|---|---|---|---|---|---|
| 1 | | | EDA CAPP | Ready / Pending / N/A | | |

Group by CTD module or by submission stage, whichever matches how the file will actually be built. Mark every N/A with the exemption relied on — an unexplained N/A reads as an omission to a reviewer.

Arabic headers: `م` / `المتطلب` / `المرجع` / `الجهة` / `الحالة` / `المسؤول` / `ملاحظات`

## 4. Comparative table

For genuine EDA-versus-others questions, and for building reliance arguments.

| Aspect | EDA (Egypt) | EMA (EU) | FDA (US) | WHO |
|---|---|---|---|---|
| Requirement | | | | |
| Citation | | | | |
| Exemptions | | | | |

Close with a short **Implication** paragraph: what the comparison means for this file. A table without an implication makes the reader do the work you were asked to do.

Arabic headers: `البند` / `هيئة الدواء المصرية` / `وكالة الأدوية الأوروبية` / `إدارة الغذاء والدواء الأمريكية` / `منظمة الصحة العالمية`
